현묘의 밭 - 와인 잡기 (720×1280 전용)

실행 방법
1. 압축을 풉니다.
2. index.html을 더블클릭합니다.

조작 방법
- 모바일: 게임 화면을 누른 채 좌우로 드래그
- PC: 마우스 드래그 또는 방향키 ← →

게임 흐름
봉투 터치 → 편지 화면 → START → 3·2·1 → 게임 → RETURN

주요 기능
- 720×1280 고해상도 캔버스
- 전용 UI 재배치
- 시간이 지날수록 여러 와인이 동시에 생성
- 기존 와인과 충분히 떨어진 무작위 위치에서 생성
- 플레이어 옆면이 아니라 머리 위 상자 윗면에서만 획득
- 와인 3병을 놓치면 게임 종료
